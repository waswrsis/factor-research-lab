# Factor Research Lab · 因子研究实验平台

面向小时级市场数据的因子研究项目：由 GPT 提出公式和假设，本地程序拟合、比较、筛选并记录证据。研究输出包括公式、预测和评分；**不执行交易，不承诺收益。**

**运行状态（截至2026-10-12 11:24 UTC）：新版服务正在运行，已完成首次拟合、一次GPT请求及三个候选评估。** 三个候选各完成15次独立拟合，记录耗时54.69、48.87、39.06秒，均低于原90秒期限；本轮已越过旧版第三候选的超时停止点。旧版失败与预付消费保留。这是当前实际执行记录，长期可靠性和因子效果仍未证实。[运行快照](docs/STARTUP_STATUS.json)。

## 实现的研究机制

- 生成、展开和筛选可解释公式，使用受限参数拟合与冻结评分规则。
- 连续90天训练窗，每15个经过日重拟合，每日更新训练视图；分钟轮询处理已闭合小时K线。
- 记录实际收件、模型发布、预测和结算时间；未来12小时标签须真实成熟后才能评分，不回填历史预测。
- 研究额度按UTC自然月计账，保留失败和消耗；重启、刷新与安装不会重发额度。
- 非线性、神经模型和正式增量结论分别受证据条件约束，自动研究不保证模型持续改善。

当前主线使用公开加密货币数据，侧重波动与事件研究。其他市场、方向预测和实盘表现不能从现有结果推断。模型配置为 `gpt-6-astra` / `high`；模型知识截止日期未知。
