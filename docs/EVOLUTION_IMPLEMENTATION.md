# 持续因子研究第四版：验收与能力边界

用户目标：补齐上一轮审查指出的六项缺口，工作全部保留在 D:/FactorResearch。
本轮不增加持仓或交易执行，也不承诺搜索一定发现有效因子。

必须以代码、测试及运行证据验收的要求：

1. 多父结构搜索；原候选保留、去重、谱系、开发反馈记忆；更多特征/尺度/宽度/维度/组合动作及兼容权重继承。
2. 接通成熟反馈→有预算研究→候选影子预测→固定期限比较→替换/保留的完整顺序循环；可从已搜索模型启动，拒绝未来训练模型。
3. 模型训练成功不直接晋级；事前冻结任务、最小增量、时序区块和跨周期比较预算；历史预测不可回写。
4. 可恢复的持久状态、单写者锁、幂等预测/结算、失败保留现用版、有限重试/预算及独立 Agent 请求服务。
5. 可选多源可用时间输入、跨标的已知信息、较细事件时间分箱与模块贡献/冗余/状态诊断；旧协议/产物兼容。
6. 对固定、仅重训、结构演化进行共同数据/初始模型/期限的实际比较；严格区分开发表现与独立确认。
7. 真实 Agent 服务提案、异常恢复、未来信息隔离及旧模型重载验证；代码和语义独立审查。

- 三模式最终均无晋级，现用模型完整输出相同；三组程序比较的主任务差值与区间均为0。此结果支持“拒绝未达标更新”的机制运作，不支持预测收益提升。

冻结开发实验：BTCUSDT/ETHUSDT/SOLUSDT、48h 输入、12h volatility 主任务、20h first_event（2/4/8/12/16/20h 分箱）、描述性 state。该次是开发程序比较，不是独立确认。

- 三模式都没有晋级，最终 incumbent digest、评分和事件概率文件哈希相同；三组主要任务差值和区间为零，`predictive_claim_supported=false`。
- 主任务成熟支持 1473/pending 39；事件 1449/pending 63；state 1512。state 是描述性任务，其低损失不能代表未来预测能力。
- refit 两轮影子估计约 -0.0232 和 +0.0219，区间不支持冻结增量，均保留旧版。
- evolve 首轮影子估计约 -0.0268，区间约 [-0.0663,-0.0015]，`target_not_met`。第二轮确实收到 4 个提案、训练 3 个新结构，开发选择仍选原模型；旧实现错误分类为 `failed: Research returned the unchanged incumbent`。
- 当前源码将此正常结果记为 `unchanged_retained` 并保存训练/成本；另将晋级字段与独立预测主张分开。这些修复需最终版本单独证据，不能改写旧 acceptance。

可以称“研究演化流程已落地，真实 Agent 与训练已接通，门槛阻止较差或证据不足候选安装”。不能称“已找到有效因子”“已超越固定模型”“历史盈利”“长期在线稳定”或“未来泛化确认”。传统期货换月、交易日历、跨品种推广也没有实际证据。
