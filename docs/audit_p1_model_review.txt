Semantic conclusions
1. Temporal filters consume each trailing scale and emit one endpoint. Nonlinear
   expert uses the current endpoint and window mean. Neither component consults a
   later stream observation; dataset-window construction remains the caller's duty.
2. Parameter counting agrees with actual architecture for tested mutations. Width,
   depth, scale, added/dropped experts and feature operations construct physically
   different layers/input dimensions. Loss and optimizer choices are consumed by
   fit_model; they are configuration changes rather than added network parameters.
3. Feature operations form an ordered DAG with only already available inputs.
   Removal of a still-referenced feature/operation fails validation. Pure trailing
   transformations preserve the supplied input window's temporal information set.
4. Static and dynamic softmax gates express relative expert allocations. Code does
   not label allocations as calibrated confidence or predictive certainty.
5. Compatible inheritance checks raw-feature order, operation definitions, window
   length, expert layout and gate/expert ordering. Copying equal-shaped but
   semantically reordered inputs is rejected. It is explicitly initialization,
   with no claim to preserve the entire function after a structural edit.
6. Training targets are simple return divided by causal volatility scale; residual
   network learns in that scaled unit. Inference combines ridge and calibrated
   residual in scaled space, then multiplies by per-sample scale before portfolio
   use. Portfolio input remains expected simple return, not a raw normalized score.
7. Neural fit and chronological calibration are disjoint. Fitting uses labels
   mature before calibration starts. Network/scaler are not refit using calibration
   after alpha selection. Caller remains responsible for the outer search/test
   cutoff and label maturity protocol.
8. Execution limits apply to pre-trade target weights. Actual post-cost/mark/funding
   exposure is observable in the ledger; no hard post-cost or net exposure limit is
   claimed. Costs and held-position drift can exceed those target fractions. A
   maintenance stress breach fails closed, without invented exchange liquidation.
