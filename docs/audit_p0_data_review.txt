Confirmed design semantics:
* Completed hourly candle available at exclusive close+5 seconds cannot execute
  at that printed close; dataset entry uses ceil(available_at, hour), hence an
  open_time=00:00 candle first enters at 02:00, after arrival at 01:00:05.
* Label is simple return between execution open and execution+12h open.
  Label maturity is exit open+declared delay; this assumes live opening prices
  arrive after that delay, independently from full archived candle receipt.
* Feature windows and outcome intervals reject hourly gaps; build_features
  resets causal rolling history. Current dataset discards incomplete features,
  so warmup/undefined feature masks cannot silently become zero model inputs.
* Chronological splits purge labels using strict maturity before boundaries.
  OOF trains only before the next validation decision and with earlier labels.
* The fixed surviving BTC/ETH/SOL sample is engineering demonstration evidence,
  not a reconstructed historical tradable universe.

Concrete initial findings (reported to root for resolution):
F1 [P1] make_dataset ignores protocol.symbols and protocol.start/end. Repro:
  source with XRPUSDT and default frozen protocol returns XRPUSDT samples.
  Data outside protocol calendar can also enter training. Require rejection
  of unexpected symbols and enforce the calendar; independently supplied
  single expected symbols may remain useful for tests.
F2 [P1] Protocol.__post_init__ accepts negative fees/slippage and invalid finite
  risk/resources: Protocol(fee_bps=-5), risk_aversion=NaN, max_parameters=-1.
  A frozen invalid protocol can create credits or invalid optimizers/budgets.
  Validate finite economic parameters and positive bounded integer resources.
F3 [P2] dataset uses canonical available_at for entry but protocol.delay for
  label maturity without verifying canonical delay equals the frozen protocol.
  An input with delay10 seconds under delay5 protocol is silently accepted.
  Validate the declared candle availability assumption before building samples.
