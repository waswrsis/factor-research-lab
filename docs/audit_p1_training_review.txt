Positive findings from inspected implementation:
- Ridge fits y/causal_scale; residual targets subtract that normalized Ridge
  prediction. Inference sums normalized baseline + alpha*normalized residual
  before multiplying by each sample's causal scale. Units are consistent.
- Neural parameter fit precedes chronological calibration. Fit labels must mature
  strictly before the split time, and parameter/scaler/Ridge fitting excludes
  the calibration block. Alpha is fitted on held-out normalized errors/deltas,
  clipped to [0,1]; the base/network are not refitted afterward.
- Gate is jointly trained with experts, while final amplitude uses held-out
  calibration. This is a chronological holdout stack, not hidden-layer OOF or
  a calibrated predictive confidence claim.
- Saved artifacts serialize numeric arrays and typed graph, plus a weights-only
  PyTorch load. Graph constructor rejects unknown task/operation fields. Proposal
  validation binds protocol hash, parent, target unit/horizon and evidence cutoff.
- Outer segment_masks checks strict label maturity before the research cutoff.
  fit_model currently trusts its caller's train mask for the external as-of date;
  this is a caller obligation unless fit_model is extended to take an as-of date.

Findings reported to root for correction:
F1: training predict()/diagnostics hard-code prediction_clip=0.1 rather than use
    Protocol.prediction_clip. A frozen custom clipping rule would be ignored.
    Required: persist actual configured clip and use it for all predictions.
F2: diagnostic_proposal accepts history entries with no evidence_cutoff and
    partition=None, then consumes alpha/status from them. Thus search-only and
    maturity claims are bypassable by an untagged scored memory entry.
    Required: require explicit search partition and cutoff on consumed evidence,
    or strictly distinguish unscored failure metadata with enforced schema.
F3: fit_model does not independently reject a graph above Protocol.max_parameters
    (the graph validator enforces only the global 1M cap), nor check protocol/spec
    lookback equality. Required: enforce actual frozen budget/schema at fit entry.
F4: caller-supplied Dataset scales are not checked finite/strictly positive before
    normalization. Internal generated datasets use a positive floor, but reusable
    fit/predict API should reject malformed scales and nonfinite samples explicitly.
