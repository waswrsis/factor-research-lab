自演化因子研究平台：分阶段落地与验收

工作目录 D:/FactorResearch。前一版 PDF 是设计论证，不是实证结论。
本次目标是可运行、可审计、可以扩展的研究原型；真实未来业绩只能在未来观察。

P0 数据与评价协议
  固定 12 小时任务、可用时间、成本、风险和预算，哈希封存。
  带校验和与版本的公开行情/资金费/标记价；缺口、重复、修订、幸存者限制可见。
  因果特征、标签成熟时间、purged 时间切分、D 盘路径约束。
  验收：反例测试 + 数据检查 + 独立语义/代码审查，缺陷修复后记录。
P1 模型、组合与独立记账
  Ridge 基线、可学习时间/非线性交互专家、静态/动态门控、回退机制。
  参数训练与结构配置分离；所有标准化只拟合训练时间。
  组合目标统一单位/期限；次根小时开盘执行、真实资金费时点、成本与逐小时 PnL。
  验收：梯度/形状/前缀因果/手工账本、市场数据端到端运行、审查。
P2 结构演化
  类型化结构、增删专家与维度、时间尺度、宽深度、损失和优化器变更。
  候选谱系、预算、失败记录、选择与一次确认分离，参数继承范围明确。
  验收：真实结构变化、同预算随机搜索对照、禁止修改协议的反例测试、审查。
P3 agent 研究循环与研究政策评估
  诊断 -> 假说/提案 -> 安全结构操作 -> 实验 -> 证据记忆。
  支持规则 agent、外部 JSON 提案及可选 API agent，来源不混淆。
  A 简单重训 / B 固定专家 / C 随机结构 / D 诊断式 agent，逐时间截点重新搜索。
  配对时间块区间、风险/成本压力、确认不通过允许退回基线；审查。
P4 冻结与影子观察
  冻结工件、哈希验证、只追加预测、成熟后评分、防重复/未来输入。
  纸面账户，不提供交易所下单入口；前瞻时长不足如实记为等待观察。
  验收：冻结与重放、篡改/成熟边界反例、运行指南、总体语义和代码审计。

首个公开数据运行使用 2025-01 至 2025-06 BTC/ETH/SOL USD-M 永续。
这是固定幸存资产的小规模工程验证，不能代表历史全市场选股或未来收益。
外层测试为 4/5/6 月；每个截点前 28 天起为搜索，最后 7 天为一次确认。
候选训练仅用搜索开始前成熟标签；确认后不改变该次结构选择；测试随后全封存。
只使用过去误差生成提案，评价协议不可被 agent 覆盖。
如遇证据不足或候选不合格，保留简单模型而非强制复杂化。

每阶段 audit JSON/TXT 保存：范围、执行证据、语义结论、审查发现、修复、剩余限制。
工程验收不等于统计或经济有效性验收。
