# 事件时间预测与自适应期限研究方案

版本：研究设计 v2.0。日期：2026 年 10 月 3 日。适用项目：D:/FactorResearch。

本方案将现有固定 12 小时收益研究，扩展为首次事件预测与有限期限选择。首版使用独立的小模型、三个时间段和真实执行规则下的收益评价，检验事件标签、持仓方式、期限选择分别带来的价值。共享训练、精细时间分布和 agent 结构搜索属于后续扩展，需要各自通过增量检验。

本文件是设计交付，不是已实现或已验证的策略。其参数是待在开发阶段核查并冻结的起始设计，不代表最优值。本次形成方案不改变原型协议、模型、历史报告，也不启动数据下载、训练或交易。

## 研究决策

采用“独立事件模型、有限期限、明确执行规则、分层验证”的路线。保留现有收益模型作为对照及可选输入，不默认共享其内部权重。模型可以不交易，研究 agent 可以提出删除模块，也可以选择不修改。

首版研究对象为 BTCUSDT、ETHUSDT、SOLUSDT 的线性永续合约公开数据，小时级特征，最多观察未来 20 根小时 K 线。这是固定资产池研究，不代表全市场效果。商品期货的交易日历、合约换月、涨跌停和夜盘另行制定协议。

首版所说的“首次事件”严格指已完成小时 K 线的收盘价首次越过指定边界。它不等同于盘中首次触价。未来增加分钟或逐笔数据时，要新建标签和执行协议，不能直接沿用首版成绩。

| 决策 | 首版取舍 | 原因 |
| --- | --- | --- |
| 预测目标 | 三个时间段的上越界、下越界与未越界 | 与 6、12、20 小时的候选期限对应 |
| 模型关系 | 新旧独立训练，先比较后融合 | 降低任务冲突，便于归因 |
| 首次事件观察 | 仅使用完整小时 K 线的收盘价 | 不从 OHLC 猜测盘中先后 |
| 退出执行 | 事件确认后的下一整点；预定期限优先 | 保持信息到达与成交顺序一致 |
| 价值估计 | 事件概率结合实际回放净收益的收缩均值 | 纳入越界幅度、退出延迟和成本 |
| 持仓 | 每标的最多一笔，入场后固定数量 | 避免重叠预测重复占用本金 |
| 自主调整 | 先调有限参数，再开放结构变更 | 每一步可被独立否证 |

## 原型基础与需要修正的地方

现有原型使用过去 48 小时的 12 个特征，组合 Ridge 基线与专家残差，输出 12 小时简单收益。回测每小时根据预测调整组合，记录手续费、滑点、资金费与账户净值。已有因果特征、按时间切分、模型冻结、预测与成熟结果账本，以及有边界的结构提案接口。

当前原始候选回测没有确认盈利优势，不能把旧模型当作有效教师。现有七天确认期与至少二十个四十八小时区块的门槛不匹配，新版本需要预先重设足够长的评价区间，不能降低旧门槛来补签旧结果。

已经查看过的 2025 年 1 至 6 月数据及其结果用于开发和回归检查，不再称为本方案的未见测试。历史公开资料以及外部模型的预训练知识可能包含市场事后信息；本地时间隔离不能完全消除这一影响。新增的真实前瞻观察仍是独立证据。

原型保留四项能力：特征时间戳与数据完整性检查、按真实成熟时间隔离样本、可审计的实验谱系、独立资金账本。新版重建事件标签接口、概率输出、持仓生命周期与期限评价接口。不能只把原来的 horizon_hours 从 12 改为 20。

## 首版研究设置

以下是建议起点。工程实现可采用这些默认值；正式市场评价前须生成完整协议快照及哈希。开发阶段作出的任何更改都要写入选择记录，在新的验证区间使用冻结值。

| 项目 | 建议起点 | 约束 |
| --- | --- | --- |
| 输入 | 48 小时、现有 12 个因果特征 | 不同时扩大数据源与模型结构 |
| 时间分段 | 第 1 至 6、7 至 12、13 至 20 根 | 禁止在一个分段内部声称逐小时精确概率 |
| 候选截止期限 | 6、12、20 小时，默认 12 小时 | 首版不连续搜索期限 |
| 小模型 | 2 个专家，初始宽度 16、深度 1 | 初版可训练参数不超过 100,000 |
| 训练资源 | 单机、2 个固定种子，分批运行 | 内存和显存占用实际测量，不承诺训练速度 |
| 训练预算 | 每个候选最多 20 轮，早停耐心 3 轮 | 相同上限；记录实际轮数、参数量与耗时 |
| 参数优化 | AdamW，初始学习率 0.001 | 初轮先固定，不让 agent 同时改学习方法 |
| 每次入场名义敞口 | 入场前净值的 10% | 不随每小时预测重设数量 |
| 单标的与总名义上限 | 入场前分别 10% 与 30% | 三标的共用本金；价格变化后的偏离另行记录 |
| 成本起点 | 单边手续费 5 bps、滑点 3 bps，真实资金费事件 | 沿用研究假设，不声称是当前账户费率 |
| 成本压力 | 基础、两倍、三倍手续费及滑点 | 不用压力结果重新挑选模型 |
| 净优势门槛 | 8 bps | 是保守策略参数，不是置信区间 |
| 期限切换门槛 | 相对同方向 12 小时方案至少改善 8 bps | 开发阶段最多与 0 bps 对照，不任意扫描 |
| 均值收缩强度 | 100 个伪观测 | 属于正则参数，不等于独立样本数 |
| 校准 | 一项联合概率温度参数 | 先验证低维校准，不为每个标的和时间段单独拟合 |

所有 bps 都以每笔入场名义金额的收益计量；1 bp 等于 0.01%。账户收益还受到实际仓位与空仓时间影响。净优势门槛应用于已经扣除估计成本的价值，不能重复扣费。

边界首轮最多比较两种预先命名的方案：固定百分比边界，以及历史波动率边界。它们不是额外乘上任意阈值的大网格。

- 固定方案的初始对称距离为 1%。这是开发起点，不是对每个资产的最优判断。
- 波动率方案的初始对称距离为过去 48 小时小时收益标准差乘以 sqrt(12)，下限为 0.5%，上限为 5%。所有统计只使用预测时已知数据。
- 一次预测对所有候选期限使用相同边界。不能选择 H 后再用 sqrt(H) 改边界，否则改变的是另一项预测任务。
- 开发阶段对事件频率、各结果支持度与成本占比作检查。如果两个方案都不适合数据，应修改设计、记录原因，再重新冻结，不能在确认或最终测试上补调。

波动率边界并不天然优于固定边界。已有加密货币研究在特定配置下发现波动率调整使交易结果变差，因此本方案将其作为对照。[相关研究的敏感性分析](https://link.springer.com/article/10.1186/s40854-025-00866-w)

## 标签与成交时间

令预测使用的信息截止时间为 f，实际可用时间为 a，预定入场整点为 t0。必须满足 f 不晚于 a，且 a 严格早于 t0。沿用原型的整点调度，t0 为预测可用之后的下一可执行整点。

P0 是 t0 时的开盘参考价格。预测提交时可以确定相对边界比例，但不能提前读取 P0；P0 在模拟入场时绑定边界。买卖成交各自施加不利滑点，手续费另记。边界相对 P0 定义，因此与有滑点的实际入场价不完全相同，这一差异进入实际收益标签。

入场后的第 k 根完整小时 K 线覆盖 t0+k-1 到 t0+k。其收盘价 Ck 的可用时间采用源数据记录的 close_time 加冻结的到达延迟。第 k 根收盘的简单收益为 rk=Ck/P0-1。

首次事件 T 是最早满足 rk 大于等于上边界 a_bar 或小于等于负的下边界 b_bar 的 k，k 属于 1 至 20。J 分别标记上越界或下越界。若窗口内没有事件，则标记 T 大于 20。正价格条件下，同一个收盘点不可能同时满足这两个边界；不利用高低价推断盘中事件。

事件 T=k 只能在第 k 根收盘实际到达后确认。最早事件退出整点为 t0+k+1 小时，除非预先确定的截止 t0+H 更早。用原型五秒到达假设时，实际退出索引为 min(k+1,H)；实现仍应按时间戳计算，而不是硬编码偏移。

| 情形 | 观察结果 | 退出安排 |
| --- | --- | --- |
| H=12，第 4 根收盘首次上越界 | 第 4 根收盘到达后确认 | 下一整点，即持有约 5 小时后退出 |
| H=12，第 11 根收盘越界 | 事件退出与截止指向同一整点 | 按事先冻结的截止优先规则记录 |
| H=12，第 12 根收盘越界 | 结果在截止订单执行后才确认 | 截止退出；预测标签仍可记为第 12 根事件 |
| H=12，前 12 根均未越界 | 12 根窗口的未发生结果 | 截止退出 |
| 持有期间新的预测方向相反 | 新预测独立记账 | 首版不修改已有仓位的边界和期限 |

标签事件类型、事件观察时间、订单决策时间、成交时间、实际退出原因分别存储。截止订单在入场时已经确定，可以在 t0+H 执行；不能以尚未到达的第 H 根收盘来提前决定该订单。

即使某次候选交易在第 6 小时退出，也保留其作为预测样本的完整 20 根市场观察，用于完整分布评分。后续价格只在其实际到达后用于标签；不能倒流到第 6 小时的交易决策。

缺失 K 线使相应标签不可完整观察时，记录为数据不完整，不得标为未发生。无持仓时不生成依赖缺口的可交易信号；持仓中若缺少退出或估值所必需的价格，回放明确失败，不通过删去该时段来改善结果。修复数据后重新运行并保留失败记录。

首版保留每个小时都发出预测的研究样本，但只能由持仓管理器决定哪些预测可用于新开仓。多个资产的资金费在整点交易前按原持仓处理，同一时刻截止与事件退出只成交一次。首版退出后至少等待下一个整点才能在同一标的重新入场，避免在一个参考价处无成本切换。

## 事件概率模型

将首次事件时间分为 B1={1,…,6}、B2={7,…,12}、B3={13,…,20}。模型输出六项首次事件概率 p_j_up、p_j_down，以及 S20。它们非负且总和为一。

建议采用竞争风险参数化。每一时间段给出 e_j 与 d_j：e_j 是此前没有事件时本段发生事件的概率；d_j 是本段有事件时先发生上越界的概率。令 S0=1，则：

```text
q_j_up   = e_j * d_j
q_j_down = e_j * (1 - d_j)
q_j_none = 1 - e_j
p_j_up   = S_(j-1) * q_j_up
p_j_down = S_(j-1) * q_j_down
S_j      = S_(j-1) * q_j_none
```

e_j 与 d_j 使用 sigmoid 输出。这是对联合概率的参数化，不是假设事件与方向独立。未来时间段索引可作为已知条件，未来行情不得作为输入。

这种拆分允许分别检查“模型知道会有波动”和“模型知道哪边先发生”。分布更准确并不自动意味着方向优势。方法基础参考竞争风险与联合事件时间预测，不能把其他领域的模型效果当作交易证据。[DeepHit](https://ojs.aaai.org/index.php/AAAI/article/view/11842)

候选基准包括：仅用开发前训练数据估计的七类频率、含历史波动率的正则概率模型，以及小型专家事件模型。网络先用现有时间滤波专家与端点及窗口平均特征专家，不声称它们已经形成经济意义上的趋势或状态分工。

主损失为完整七类结果的负对数似然。完整 20 根未发生的样本使用 -log(S20)。第一版所有训练样本统一等待整个 20 根窗口及其到达延迟结束；无需通过提前加入快速触发样本来加快反馈。发生缺口的样本不用作完整标签，部分观察似然作为后续研究。

禁止根据结果类别或兑现快慢任意加权损失后仍把输出直接称为真实概率。若未来引入时间价值，首先放在决策层；概率模型仍以适当评分规则与样本外校准为准。[概率评分规则研究](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)

两个固定种子的七类联合概率先等权平均，不根据回测成绩挑选种子。概率校准在独立的历史校准段进行：对平均后的七类概率作一项联合温度变换并重新归一化，再汇总出 S6、S12、S20，确保概率总和与累计事件单调性不被破坏。各期限、各标的及实际入场子集分别报告校准结果；样本不足时报告不确定，不拟合更多校准参数来掩盖问题。

## 实际交易价值与期限选择

在本方案的延迟执行规则下，上越界后的成交收益通常不等于正的边界距离，下越界后的成交收益也不等于负的边界距离。未发生事件时的截止 open 与最后一根已观察 close 也可能不同。

因此，上一轮讨论的理想公式 a*F_up-b*F_down+S*m0 只作解释工具。其条件均值位于边界内的约束仅适用于同一观察价格下未越界的收益，不能强加给有执行延迟的真实成交收益。

首版不额外训练复杂的到期收益网络。对每个完整入场样本，在相同市场路径下离线计算两方向和三个期限的六个实际净收益 Y(d,H)，其中包括固定数量、事件延迟退出、截止优先、双边手续费、不利滑点及持有期间资金费。这些是无市场冲击假设下的候选行动标签，不代表现实可以同时执行六笔交易。

对每个 H，将类别重新聚合为“截至 H 的各首次事件时间段和方向”以及“截至 H 未发生”。例如 H=6 只有三类，H=12 有五类，H=20 有七类。H=6 的未发生类别包含第 7 至 20 根才发生的样本及始终未发生的样本。首版统一合并它们，不按照 H 之后的真实结果为第 6 小时的决策选择有利收益均值。

用完整二十小时类别作离线数学分解，本身不必然构成泄漏；关键在于交易决策只能使用当时预测的概率，不能使用真实未来类别。本方案采用重聚合，是为了减少参数与类别稀疏程度，并简化审计。

从训练段估计实际类别净收益均值 mu(d,H,c)，并向该方向、期限的总体均值作收缩：

```text
mu_shrunk(d,H,c)
  = [n_c * mean(Y(d,H) within c) + lambda * mean(Y(d,H))]
    / (n_c + lambda)

V_hat(d,H) = sum_c p_hat_H(c | current_information) * mu_shrunk(d,H,c)
```

所有均值、收缩与成本假设只用候选可见的训练资料。首版将三标的按入场名义金额标准化后的收益合并估计，共有 2*(3+5+7)=30 项类别均值；单标的及波动状态差异用于诊断，不另外拟合几十组均值。类别计数可用于正则化，但不被当作独立统计试验数。若关键类别在训练中没有可用支持，则相关行动标为价值不可估，不因概率看起来很高而开仓。

这是一个低参数的价值近似。它假设同一结果类别内，剩余特征对净收益的影响有限。概率校准良好不能证明该假设。必须在开发和后续区间检查预测价值与实际 Y(d,H) 的偏差、排序和状态稳定性，并设置两个独立开发门槛：默认 12 小时价值是否可靠，以及期限价值差是否可靠。

默认价值门槛记录可估行动覆盖率、各价值分组的预测与实际均值偏差、方向排序及分时段稳定性；期限门槛记录 V6−V12、V20−V12 与相应真实行动收益差的偏差、排序，以及切换子集的支持度。分组边界、最小支持度、允许偏差和通过规则在开发末冻结，不能看过确认结果后补定。默认价值不通过，C 不进入经济晋级，保留预定简单基准或空仓；默认价值通过而期限差值不通过，保留 C 的固定 12 小时研究版本，不开启 D。这些开发诊断本身不构成正式盈利证据。

若需要增强价值层，下一版本再比较基于时序样本外概率的正则价值回归，不能悄悄加入更复杂价值头继续使用原确认集。

由于 Y 已包含全部交易与持仓成本，计算 V_hat 时不再次扣除同一批成本。“固定政策成本压力”保留原模型、价值估计及规则，仅提高成交与记账成本；“预先规定的成本感知政策压力”则按新成本同步重算训练行动收益与收缩均值，再按冻结算法决策。后一种仍只能使用历史训练资料，不重新挑选模型、门槛或时期。两种结果分别报告，首版以固定政策压力作为晋级依据。

首版的期限选择采用以下固定顺序，防止同时改变方向与期限导致无法归因：

1. 在同一时刻，对 12 小时方案比较做多与做空的 V_hat，选其中较大者作为方向；数值完全相等时不交易。
2. 如果该方向 12 小时的净价值未超过 8 bps，不入场。首版不靠另一期限来挽救一个未达到默认入场门槛的信号。
3. 固定期限版本持有 H=12；动态版本在同方向的 6、12、20 小时中比较净价值。只有相对 12 小时改善超过 8 bps 时才改变期限。
4. 多个非默认期限的估计相同，选择较短期限。未达到切换幅度则保持 12 小时。
5. 价值不可估、输入不完整、模型版本验证失败或敞口限制不允许时不入场。没有交易是合法结果，但不能作为预测成功证据。

这些门槛是待冻结的决策参数，不是统计置信保证。初版不把少量模型之间的分歧直接变成逐笔置信区间。默认期限可以在后续设计中改变，但不能因测试期表现而追认。

每笔数量以入场前净值和入场参考价计算，持有中保持不变，直到退出。三标的共用本金，不能为每个预测分配一份独立本金。同一整点先处理已持仓资金费及应退出订单，再处理合格新订单；新订单按标的代码字典序准入，共用该整点退出完成后的净值快照。既有仓位占用资金与名义敞口，容量不足的候选跳过，不临时改变排序。首版以研究用连续合约数量记账，后续加入最小下单量和最小名义金额时须单独验证。

敞口与保证金仍按真实价格更新；入场时的上限并不保证持有期间因价格变化而始终不超限。达到冻结的账户维护压力条件时中止该回放并记录，不假设止损总能按边界成交。

期限选择的 V_hat 是局部价值代理，未完整解决未来入场机会与资金占用的动态规划。最终判断依据为共同日历上的组合净值及风险，而不是只按单笔收益或简单收益除以持仓小时排序。

## 新旧训练的融合顺序

首先独立训练事件模型，并保留“不使用旧预测”的版本。旧收益预测若作为特征，必须按时间向前生成：每个预测只能来自在该时点前已成熟的标签。不能使用全样本拟合值，也不能把固定的旧收益模型当作真实标签。

新旧对照匹配训练资料、特征可用时间和开发预算。原模型用于概率任务时不能把收益数字直接解释为胜率；门控权重、神经残差幅度 alpha 也不等于概率置信度。

只有独立融合显示稳定增益后，才允许共享专家内部向量，并给事件、收益等任务分别设置门控。原收益任务权重为零的版本必须保留。不同损失先统一尺度，再比较固定权重；实际出现训练失衡时，才把 GradNorm 或 PCGrad 纳入有界对照。其技术作用是处理多任务优化，不是证明金融收益。[GradNorm](https://proceedings.mlr.press/v80/chen18a.html)、[PCGrad](https://arxiv.org/abs/2001.06782)

首版市场确认使用冻结的模型和价值估计，不在确认或测试段更新权重。后续在线版本另作完整实验：先预测并记录，再等待标签成熟，最后按冻结日程更新。新增模型只能影响之后的预测，不能改写旧预测、旧期限或旧账本。

建议后续更新节奏为每小时推断、成熟数据足够后定期校准、按预设周期批量训练参数、较低频率比较结构。具体周期必须在在线实验启动前冻结，不能依据测试期亏损临时换节奏。

## 对照实验与归因

保留原始 A0 结果作历史参照。A0 的组合优化、杠杆与持仓规则不同，不能用 A0 与新版的差额证明某个单独组件有效。正式归因新增匹配后的 A1。

| 对照 | 预测 | 交易方式 | 主要问题 |
| --- | --- | --- | --- |
| A0 | 现有历史冻结模型 | 现有组合优化及每小时调整 | 历史参照，不作单一组件因果比较 |
| A1 | 相同训练资料的固定 12 小时收益模型 | 每小时更新目标敞口，使用新版共同名义上限 | 提供风险预算匹配的原任务对照 |
| B | 与 A1 相同的收益预测 | 新事件退出规则，固定 H=12、固定数量 | 固定数量与事件退出这一组合协议是否改善净表现 |
| C | 新事件概率模型及收缩价值层 | 与 B 相同的退出与仓位约束，固定 H=12 | 新预测目标与价值决策层的联合增量是否有效 |
| D | 与 C 完全相同的模型、校准、方向规则 | 仅增加有限期限选择 | 动态期限是否提供增量价值 |
| E | 经检验的旧预测输入或共享训练 | 保持 D 的执行与决策协议 | 融合是否增加价值 |
| F | 受限 agent 结构候选 | 保持通过验证的训练与交易任务 | 搜索是否优于固定结构及同预算随机搜索 |

A1 到 B 同时改变数量管理、截止期限、事件退出及冷却，比较的是执行协议组合，不单独归因于事件退出。若要回答早退出本身的作用，再预先增加固定数量、仅按 12 小时截止退出的对照，不用事后叙述代替消融。B 与 C 的入场信号含义不同，不能声称只有神经架构发生变化。B 使用原收益信号和开发阶段固定的成本门槛；C 使用实际事件价值。记录它们的覆盖率和交易频率，并增加匹配换手的诊断作为补充。

C 与 D 使用相同的 12 小时方向及入场门槛。在每个相同潜在入场样本上，先做配对的六种行动收益诊断，以分离期限选择本身；随后各自运行真实持仓组合。配对诊断中的虚拟单允许时间重叠，因此不能相加为可交易的账户收益。由于真实持仓时长不同，后续可用入场机会自然不同，这属于完整政策效果，不能通过事后删样本来强行匹配。

同时完整报告固定 H=6、12、20 的结果，它们在期限消融中都使用同一个 12 小时方向与入场门槛，只改变退出期限。动态版本的正式比较对象，是开发阶段选定并冻结的固定期限政策，以及固定 H=12 的配对消融。测试期表现最好的固定期限只作描述，不能倒过来当作事前选定的基准。

每次新增组件只允许一个主要研究问题。首版单轮开发限制每个边界方案最多四个事件模型配置、两个种子；两种边界合计最多十六次开发事件神经拟合，种子和失败尝试都计入，不通过重新命名批次增加预算。频率及正则概率基准、策略阈值对照和校准尝试也列入完整选择记录。旧收益模型拟合、旧预测的时序样本外生成以及后续 E/F 另列预定预算，不隐含包含在十六次内。首版默认不在候选选择后重拟合基础模型；若要重拟合，必须在独立校准开始前登记额外预算、拟合截止和重拟合规则。预算控制个人原型规模，不构成多重比较已被解决的证明。

P3/P4 的 C−B、D−C 等组件比较属于开发证据。P5 的正式主要假设只检验一个预先指定的最终候选相对一个冻结经济基准，以及相对不交易的净效用。其他比较作为消融报告，不能借用这两个检验的结论同时宣称所有组件已得到正式确认。若最终选择 D，经济基准为同一事件模型下开发选定的固定期限政策；若仅选择 C，经济基准为预先选定的 B。不得在确认段更换分支或基准。

## 数据隔离与验收标准

建议正式研究先具备至少十二个月训练资料，再安排九十天开发搜索、六十天独立概率校准、一百八十天一次性确认及一百八十天最终测试。首次执行前根据实际数据完整性锁定准确日期和 UTC 边界，不能根据收益分布挑选时期。该安排共需要约二十九个月资料；每段还须预留特征暖机与标签成熟所需的边界余量。

该长度是起始研究安排，不是样本量充足的保证。数据预算不足时可以完成工程与探索性研究，但保持“证据不足”，不缩短区间后声称已确认。不同资产同一时刻的相关性、重叠预测及连续持仓都减少有效信息。

开发搜索阶段内部保留按时间隔离的临时校准数据，模拟完整候选流程。P3/P4 仅使用开发搜索及临时校准资料。进入 P5 前登记基础模型、标准化和收益均值各自的最终拟合截止；默认保留选中的训练段模型与均值，不作最终重拟合。之后只在独立六十天校准段拟合最终温度。最终校准段不用于训练基础网络、修改价值均值或挑选架构。进入确认前冻结所有对象，确认及最终测试均不更新参数、校准或交易门槛。

按样本实际 label_available_at 清除跨界样本。首版标签成熟统一取入场后完整二十根窗口的最后可用时间，因此不能只沿用十二小时清除规则。特征和标签缺口、标准化、价值均值和旧模型样本外预测都受同样的历史截止约束。

一次性确认通过后模型与规则保持冻结，进入最后测试，并使用同一验收规则。失败后可以开始新研究版本，但已经打开的确认和测试资料要登记为已用；不能反复在同一段上调整直到通过。长达两段一百八十天的冻结评价会暴露模型老化，这是首版静态模型研究的真实限制；预设滚动更新属于后续另一个实验，不能中途加入。

各经济评价段独立从 100,000 USDT、零持仓起步，不继承前一段的历史收益或仓位。距区间结束不足二十小时停止新开仓，已持仓按原规则自然到期；不因期末表现选择提前清仓。该开仓截止同时应用于所有期限政策，避免长短期限享有不同尾部机会。准确的最后入场、价格可用与报告边界在 P0 以时间戳冻结。

| 验收层 | 必须提交的证据 | 失败处理 |
| --- | --- | --- |
| 工程语义 | 时序、标签、概率、退出、账本与版本完整性检查 | 修复后重跑工程验证 |
| 预测有效性 | 七类对数损失、各期限 Brier 分数、分组校准、事件率与条件方向诊断 | 保留简单概率基准，不宣称事件模型有效 |
| 交易增益 | 共同日历的净值、回撤、换手、敞口、占用、费用、资金费、分时段结果 | 不因命中率提高而晋级 |
| 期限增益 | 相对冻结固定期限的配对净效用，以及组合回放结果 | 保持固定期限 |
| 绝对可用性 | 相对不交易的净表现、基础成本下正的统计证据、风险约束 | 优于亏损基线也不能晋级 |
| 前瞻一致性 | 冻结后逐时记录、成熟评分与独立纸面账本 | 不把历史回放算作实际经过的前瞻时间 |

主要预测指标为七类负对数似然；主要经济指标为 U=mean(r)−gamma*var(r)/2，其中 r 是共同日历上的小时账户净收益，gamma 是在开发前约定的风险惩罚系数，初始建议为 3。单位始终保持小时口径，年化仅用于展示，不通过改变口径提高分数。交易筛选子集也要单独报告，但不能只公布该子集而隐藏所有预测的校准结果。

经济确认用按日历对齐的组合小时序列，成对重采样相同时间区块；不对标的样本行独立 bootstrap。默认采用移动区块 bootstrap：从共同小时序列的连续窗口有放回抽取整块，拼接后截取到原序列长度，每次对两项政策重新计算净效用及差值；固定随机种子，重复 10,000 次，用百分位区间。主区块长度为四十八小时，一百六十八小时为必须通过的保守敏感性检查。每个评价段、每种区块长度均须具备至少二十个完整且数据齐备的非重叠区块作为最低长度检查；这不意味着这些区块真正独立。

一百八十个完整日历天约容纳九十个四十八小时块、二十五个一百六十八小时块，边界裁剪或数据问题后仍需重新计数。两种长度都必须满足门槛，且下述两项主要区间的下界都大于零，才满足统计晋级条件；主结果通过而长区块结果不通过，保持证据不足。不能通过产生更多 bootstrap 重复次数弥补原始观察太短。

初始晋级门槛：基础成本下，相对冻结基准的净效用差与相对不交易的净效用，其预先约定的区间下界均大于零；同时账户最大回撤不超过 20%，无账本或执行失效。每种区块长度下，两个主要检验使用 Bonferroni 分配后的每项 97.5% 双侧区间作为保守起点；要求两种长度同时通过进一步收紧晋级，不通过择优采用区块长度扩大结论。在单项覆盖率有效的条件下，每种长度的两个区间具有至少 95% 同时覆盖率。区块 bootstrap 仍依赖时间过程假设，非平稳和尾部风险可能影响覆盖率；该规则不是收益保证。

两倍成本的固定政策压力下要求净收益与净效用点估计仍为正且风险约束满足；三倍成本及成本感知政策作为诊断报告，不再据此挑选版本，也不能用成本感知的通过替代固定政策失败。若存在多个候选进入确认，须在打开结果前重新定义多重比较控制；首版只允许一个开发选出的候选进入一次确认。任何经济门槛应在确认开始前写入协议。

开发阶段另做最小可识别效应与统计功效估计：以预先冻结的最小实用改善为输入，用保留相关结构的区块模拟估计当前长度是否可能识别它。不得把“有二十个区块”解释为已经有足够把握。最小实用改善的数值在开发完成时记录；未记录不得进入正式确认。

应记录全部开发尝试，补充选择偏差与回测过拟合诊断。一次历史 bootstrap 或增加几次随机种子不能消除反复搜索带来的偏差。[回测过拟合研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

## 必须通过的反例检查

- 公平随机游走：允许更长窗口时触及率可以提高，但计入所有到期结果后不得凭空产生正期望；费用应降低净收益。
- 先下越界再上涨：做多事件标签保留首次下越界，不按最终上涨改写。
- 同一小时 high 和 low 都越界：首版只依据收盘观察，不猜盘中顺序。
- 事件收盘尚未到达：不得提前平仓；预先提交的截止订单仍可执行。
- 越界后下一开盘反向跳动：按实际参考成交价记账，不把利润固定为目标距离。
- H=6 的行动标签：不能按第 7 至 20 根的结果筛选其未发生收益。
- 完整窗口未成熟或数据缺失：不得填成失败或未发生事件。
- 一小时多个有效预测：只记录预测，不复制本金或覆盖已有仓位。
- 同整点截止、事件与资金费：顺序固定，退出只发生一次，费用不重复。
- 模型更新或架构变更：旧预测及原期限不可变，更新只影响之后的新预测。
- 所有价值低于门槛：保持空仓；无交易不能获得虚构的命中率和夏普。
- 延长未来数据尾部：不得改变过去时刻的特征、已生成预测、已提交订单或已结算账本。

## 后续结构演化的边界

Agent 每次提出一项主要变化，附带当前搜索区间内的证据、预期改进、失败判据和预算。允许增删特征、变更有限时间尺度、增删专家、调宽深度，以及经过单独验证的任务共享。禁止同时修改标签定义、成本、最终评价区间和通过标准。

增加模块必须比较删除该模块的版本。结构不变、降低复杂度与返回简单基准都属于正常研究结论。外部 agent 不读取确认或最终测试结果来继续选择同一候选，也不能把相关论文或预训练中的历史表现当作本项目的未见证据。

从三个时间段细化为逐小时输出、引入条件价值网络、改成盘中触价、持仓中重新优化退出以及扩展到商品期货，均作为新研究问题，单独设协议和对照。不能把这些扩展的潜在收益提前计入首版的可行性结论。

## 开始正式评价前的冻结清单

以下清单由后续实施根据数据审计和开发结果补齐，不是额外的用户审批流程。任何条目缺失，只能运行标为工程或开发的实验。

- [ ] 锁定数据源、版本、完整性报告、确切 UTC 日期及资产池。
- [ ] 锁定收盘观察、可用时间、下一整点执行、截止优先及退出后冷却规则。
- [ ] 锁定一个主要边界方案、三个期限与默认方向及入场规则。
- [ ] 锁定模型、分项拟合预算、种子及集成方式、旧预测使用方式和全部开发尝试清单。
- [ ] 锁定基础模型、标准化、收益均值的最终拟合截止，以及独立温度校准区间。
- [ ] 锁定真实行动收益估计方式及默认价值、期限差值的覆盖率、偏差、排序与稳定性门槛，验证无重复扣费。
- [ ] 锁定共同仓位、成本、资金费、维护压力触发数值和缺失数据处理规则；研究压力条件不冒充交易所完整保证金模型。
- [ ] 锁定账户初始状态、期末开仓截止、已有仓位退出及最后估值规则。
- [ ] 锁定最终候选分支、唯一经济基准、两个主要假设、风险惩罚系数、最小实用改善与统计功效结论。
- [ ] 锁定确认和最终测试权限、两种区块长度及最低块数、bootstrap 方法与次数、区间及失败后的新版本流程。
- [ ] 锁定固定政策成本压力的晋级规则，以及仅作诊断的成本感知政策计算规则。
- [ ] 完成阶段语义审查、代码审查、反例检查及独立账本对账。

本方案首先要证明：相同风险预算和可执行规则下，新的预测目标能否增加净价值；其次证明：有限期限选择能否提供额外增益。只有这两点有后续数据支持，才值得扩大矩阵、共享任务和结构搜索的范围。
