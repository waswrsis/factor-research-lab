# 自适应因子研究方案与再评估

第三版建议稿，2026 年 10 月 3 日。

本方案围绕小时级加密货币与期货研究，重新组织既有多专家设计、训练稳定性报告与后续批评意见。范围是因子发掘、研究评分和迭代训练，保留未来扩展到其他市场的接口，不纳入持仓、交易决策或执行。本轮只做纸面设计与分析，没有新增模型训练、市场实验或硬件测量。

建议把平台定位为能够比较、保存和修订因子假设的研究系统。专家数量、表示维数和组合方式都是可研究的选择；长期成果可以是更好的表示、更合适的组合、更简单的模型，或者一个有依据的否定结论。

综合判断是有条件可行。训练和研究流程可以形成闭环，小规模本地验证具有合理路径；多专家优势、结构搜索价值及持续发现有效因子的能力仍待实证。这一版的改善在于让这些主张更容易被检验，同时减少首版的管理负担。

## 对既有建议的取舍

| 原有想法 | 吸收方式 | 需要保留的批评 |
| --- | --- | --- |
| 多种专家各自学习，再学习组合 | 保留可学习表示和任务组合；专家可服务多个任务 | 不能根据模块名称推断其功能，多个专家未必优于一个小模型 |
| 自动增加矩阵或维度 | 改成增删、合并、替换和保持不变均可选 | 新维度也增加容量和搜索机会，不能直接算作新发现 |
| 用评分取代交易决策 | 保留当前研究输出与因子质量两层记录 | 组合权重、输出概率和因子质量不是同一种分数 |
| 冻结表示后检验，再比较整个体系 | 保留，增加容量与选择程序对照 | 冻结生成器仍不能消除下游参数增多的影响 |
| 训练稳定性与收敛验收 | 保留输入、损失、更新和停止诊断 | 工程停止不能证明全局最优，更不能证明样本外有效 |
| 自适应预测期限与概率分布 | 保留为可选任务，先固定共同评价对象 | 区间更宽、期限更长可能改变问题难度；分布尖锐不等于可信 |
| 独立确认与完整版本 | 保留最小必要记录，少量候选才进入确认 | 多次重切同一资料不能制造新的独立证据 |
| 自动研究 agent | 从初期就参与解释与提案，逐步开放有预算的试验 | 它本身也要与简单搜索比较，不能自己改当轮的评价标准 |
| 越全面的管理越可靠 | 首版压缩为统一实验记录与检查程序 | 多套管理服务、高级综合分和全自动修复暂不建设 |

不预设市场有固定比例的随机噪声，也不把增加指标数量作为进展指标。噪声与可预测性的判断要绑定目标、期限、资料和评价方法。来自同一资料的更多变换，可能改善信息的可利用程度，但不能据此宣称获得了新的外部信息。

## 研究对象与最小结构

一次研究先说明：候选相对哪个参照，在什么任务、什么信息条件和什么预算下，预期改善什么。每轮设置一个主要主张，其他结果用于诊断或预先声明的补充检验，避免事后挑选最漂亮的任务作为成功依据。

系统保留四项核心功能。初期可以在同一个本地程序中实现，不要求四个独立服务。

| 功能 | 内容 | 输出 |
| --- | --- | --- |
| 资料与任务 | 可用时间、预处理、目标、成熟规则、参照与主评价方法 | 任务和资料约定 |
| 表示与组合 | 简单因子、可学习表示、因子组和任务组合 | 因子值与当前研究评分 |
| 比较与记录 | 训练检查、表示检验、完整模型比较、证据范围 | 统一实验记录和质量档案 |
| 研究迭代 | 人或 agent 提出修改，固定程序执行与比较 | 保留、修改、归档或等待证据的候选 |

训练管理、版本管理和证据管理成为上述功能中的共同规则。每个实验保留资料与任务版本、候选与参照、训练规则与预算、实际停止原因、结果和证据状态，足以复核发生了什么。

首个验证任务建议采用固定观察范围的未来波动研究，先把目标构造、结果成熟、表示比较与评分反馈走通；波动定义、观察长度、输入截止、标签成熟和主损失在正式实验前冻结，本稿不指定数值。首次事件分布作为后续独立任务，单独检验方向与兑现时间方面的主张。首个任务即使成功，也不证明方向或事件预测、其他市场或所有因子有效；负结果也只削弱对应候选在该任务上的主张。

量价关系、市场状态、标的联动可以作为独立描述任务或辅助表示，不能因它们不直接预测价格就否定其用途。描述成功也不能自动登记为预测发现。以波动任务起步是控制首轮范围的设计选择，不是文献或本项目已经证明的最优任务安排。

## 可学习的部分与可修改的结构

保留用户希望在指标内部学习权重的设计。一个表示生成器可学习历史窗口权重、平滑尺度、输入交互和低维表示；任务组合可以学习如何使用这些表示。示意关系如下：

```text
当时可用资料 X_t
    → 各表示 z_m,t = f_m(X_t; θ_m)
    → 任务研究输出 s_k,t = g_k(z_1,t, …, z_M,t; φ_k)
```

这不是规定必须使用 M 个神经网络。f 可以是固定公式、可学习时间滤波、小型非线性模块或它们的组合。g 可以从简单组合开始，只有存在可检验理由时才引入状态依赖的门控。若额外直接输入原始资料，要在候选和参照中明确并保持比较条件一致。

固定结构中的连续参数 θ、φ 可以用适合的梯度方法学习。增加一个模块、改变维数或替换算法属于外层研究动作，不能把普通反向传播描述为自动完成全部离散结构修改。具体采用搜索还是可微松弛，以后作为方法选择比较。

潜在维度在重训后可能重排或改变含义，因此质量档案默认绑定整个表示模块或因子组。只有身份稳定且能够单独检验的因子，才长期逐维追踪。专家权重表示当前组合怎样使用其输出，不直接等于贡献大小、因子质量或因果效应。

## 评价先明确增量属于谁

保留两条评价线，并把昂贵比较集中到少量候选。

第一条评价冻结已经在允许资料上学得的生成器，在共同的未来样本上检验表示。至少区分两种问题：现有因子加入候选后是否有实际改善；在可比容量或资源约束下，候选表示是否优于其他表示。相同的下游模型名称不保证容量相同，因为输入维数可能不同。

根据主要主张选择维数受限、同规模简单表示或相同复杂度预算等对照，说明哪些条件匹配、哪些仍有差别。初期无需为每个候选同时运行所有对照。若改善只能归属于更大容量或整个配置，按对应范围登记，不强行归因给某个因子。

第二条评价允许整个模型按既定程序重训，比较完整候选与简单参照的任务表现和资源代价。第一条无改善、第二条有改善，可能支持组合或完整体系的价值；不能直接宣称得到可独立复用的新因子。

若事先声明某因子组依赖非线性交互，即使简单表示检验失败，也可在预算内保留一次对应组合检验。没有事先声明的复杂解释可以成为下一轮假设，不能追认本轮已经成功。删除模块后不重训观察当前依赖，删除后重训观察可替代性，按研究需要选择，不要求所有候选都运行两遍。

把增量写为同一任务、同一评价样本上的损失差，便于明确主张：

```text
Δ_k = 平均损失_k(参照) − 平均损失_k(候选)
```

损失越低越好时，正值表示候选更好。生成器、下游模型、校准与选择程序均不得使用该确认样本调试；有缺失或范围限制时，比较共同覆盖样本，同时报告覆盖差异。样本资格和允许的覆盖规则事前确定；若共同范围因候选而缩小，Δ 只支持该共同范围内的条件结论，不能据此认定原定完整范围改善。数值失败造成的缺失作为异常记录，不能裁去后仅报告成功样本。这只是指定方法下的可用性增量，不是新增信息量或因果作用的测量。

在双方可用历史与训练资料相同、变换不引入额外资料的前提下，候选是原输入的变换。它可能比既有因子更有用，也可能让有限模型更容易学习，但这与增加新的数据来源不同。三个结论分别保存：相对已有因子改善、相对原始输入参照改善、完整体系改善。

## 两层评分与证据状态

当前研究输出按任务解释。例如事件概率、波动估计、相对强弱、关系异常程度，不强行转成同一个分值。未经校准的强弱分数不能直接叫作概率。

因子质量档案优先记录任务内增量、适用范围、覆盖、不同时间段表现、估计不确定性与资源代价。初期不建立跨任务万能总分。若以后需要综合排序，固定其用途和权重；学习评分权重本身属于新研究，不与被评价候选同步变化后仍沿用旧结论。

数值健康与优化停止单独记录，不参加质量加分。证据状态分为开发支持、独立确认支持、未达到预定目标、证据不足、流程无效。流程无效指数据或计算不能支持解释，不等于已经证明候选没有信息。

每轮事前说明什么幅度的改善值得进一步保留。对于增量 Δ 与预定的最小有意义改善 δ，在不确定性评价具有适用依据且已经考虑本轮比较和选择的条件下：

| 结果 | 可作出的判断 |
| --- | --- |
| 增量区间下界高于 δ | 支持该候选达到规定的任务增量，仍限于确认范围 |
| 增量区间上界低于 δ | 不支持它达到本轮规定的增量要求 |
| 区间跨越 δ | 证据不足，不能强行判成成功或无信息 |

这是一种决策口径示例，不在本稿选定区间算法或置信水平。时间依赖、市场变化或样本不足使区间假设难以成立时，保留估计与局限，不能包装成精确保证。可核验的描述工具或更低成本的等效表示，可以按其事先声明的用途单独保留，无须伪装成预测增量。

## 自适应期限与噪声控制

期限选择适合保留，但先给所有候选一个共同问题：同一组预定期限，或同一固定观察范围内的首次事件分布。评价采用预定权重和共同成熟样本，随后单独检验如何选择展示或研究的期限。选择程序只读取当时信息，不依据后来是否兑现修改过去的预测。

若按概率评价，可使用适合目标的对数评分或 Brier 评分等；严格适当评分规则在其适用条件下鼓励报告真实概率分布。它不保证有限样本估计准确，也不替代时序隔离。[Gneiting 与 Raftery 的原研究](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)

首次事件任务保留完整观察期内无事件的结果。概率在时间上的集中程度描述模型预测，不单独证明模型可靠；不能把密度峰值直接乘成额外置信度。置信程度还需要未见资料上的校准、评分和样本支持。自选期限上的改善，只能支持相应选择程序，不能直接宣称所有期限都改善。

噪声控制依靠可比目标、适度复杂度、支持度检查与样本外确认共同完成。某些条件头样本不足时，提高损失权重不能增加事实信息；可以简化、限制范围或等待资料。低相关、输出平滑和高置信度均不单独构成有效因子的证据。

标签定义必须尊重资料分辨率。例如一根 K 线内同时触及两个边界而无法判断先后时，要按事前规则使用更细资料或记录歧义，不能凭需要补出先发生事件。未成熟、缺失和完整观察后无事件也分别处理。

## 训练稳定与长期迭代

训练层保留四类检查：资料与目标有效，损失及掩码正确，参数与实际更新可诊断，停止与检查点选择可复核。非有限结果明确处理，不能静默填零；低梯度、小更新或训练结束也不自动写为有效收敛。

固定特征上的适当线性损失，加上覆盖全部系数和偏置的正二次正则，可在相应凸性和平滑条件下形成具有唯一有限最优解的基准。数学上存在收敛依据，仍需实际求解的最优性诊断，例如合适的梯度残差。非凸网络只报告可核查的优化诊断和工程停止，不承诺达到全局最优。第二版中的事件似然推导继续作为事件任务专用参考，不扩展成全部任务的证明。

参数训练与结构研究分开。滚动回放遵循先记录当时输出、等待结果成熟、评价、再按预定程序更新。评价资料是否能在之后用于训练，取决于声明：若评价冻结的顺序学习算法，可在标签成熟后依其固定规则学习；若评价固定模型的留出表现，该确认窗口内不得重训或调试该模型。二者不混用。

比较滚动与冻结方法时，要在相同信息截止和预定资源安排下进行，不能用新结构加新资料的结果减去旧结构旧资料的结果，认定差额全来自结构。市场变化也不意味着参数最终应停止变化。

版本记录绑定预处理、表示、组合、任务、评分解释、校准和更新程序。失败候选不覆盖已接受版本，历史输出不回写。旧版也可能失效，此时应标明无合格研究输出或仅提供仍有适用依据的参照。

## Agent 的作用与搜索预算

agent 从初期就可以读开发诊断、提出假设和解释差异。允许的结构动作先限制为增加或删除因子组、调整表示维数、合并模块、替换组合方法和修改一类训练设置。需要联合变化时按完整候选评估，降低细粒度归因要求。

每轮先确定主要问题、候选范围、单候选预算和总预算，先运行便宜检查，再让少数候选获得完整比较机会。预算截止、没有新假设或资料不足，都可以结束该轮。有效流程建立后，即使当前复杂模型还未胜出，也可以为有理由的结构假设安排有限探索，不要求先获得成功才能研究。

agent 的研究价值也要评价。参照可以是相同搜索空间内的预定枚举或随机搜索，比较完整选择程序在相近总资源约束下的确认结果与耗时，记录模型调用等额外成本。已有 NAS 研究在特定语言和图像基准上表明，简单随机搜索值得作为强参照；这不证明它会在本项目胜出。[Li 与 Talwalkar 的原研究](https://arxiv.org/abs/1902.07638)

agent 不接收当轮独立确认的详细结果以继续改同一候选，也不为候选修改门槛。事后根据已经查看的结果开展下一轮开发是允许的，但这份资料的身份随之改变。任务或评分标准若要改，登记为新研究问题，重新建立比较依据。

## 有限资料下的验证安排

大多数比较留在开发资料中，少量候选连同任务、适用范围、选择程序与主要声明冻结后，才进入未见资料确认。模型选择本身会对有限评价资料过拟合，训练阶段没有泄漏并不足以解决这一问题。[Cawley 与 Talbot 的原研究](https://www.jmlr.org/papers/v11/cawley10a.html)

保留搜索规模、失败候选、并列主张及每次确认记录；这些记录帮助评估偏差，但记录本身并不会自动消除多重比较。确认的统计安排要与事前声明相匹配，不能反复查看直到出现好结果。

训练样本的目标必须在当时成熟，预处理只使用允许的历史。重叠观察区间与跨标的共同冲击要在不确定性分析中考虑；多币种不自动等于很多独立重复实验。历史修订、回填及标的覆盖也属于可用性核验范围。

确认资料看过之后可以转为开发资料，不能恢复成未见。后续确认依靠真正新增且已成熟的资料，或事先保留的其他资料。若没有足够独立证据，产物可以停在开发阶段有改善，不强制给出已确认结论。

以下是下一阶段的验证顺序，本轮均未执行。

| 阶段 | 要回答的问题 | 何时止步或调整 |
| --- | --- | --- |
| 资料与受控检查 | 目标是否可观察，流程能否恢复已知结构并识别无信息对照？ | 时间或标签不成立先修复；受控结果不当作市场证据 |
| 简单基准 | 固定任务能否被可复现地训练与评价？ | 数值异常、目标未被正确求解时先定位问题 |
| 一个候选表示 | 是否提供足够的任务增量，改善属于表示还是容量或组合？ | 未达目标保留参照；证据不足不强行晋级 |
| 有限结构研究 | 预先说明的修改是否值得其资源代价？ | 总预算耗尽结束；不因没有胜出而无限扩展 |
| 独立确认 | 冻结的候选和声明是否得到新证据支持？ | 无支持则限定结论或归档；已用资料不再充当独立确认 |
| 顺序更新 | 固定更新算法是否优于不更新或简单更新参照？ | 若增加方差或资源却无足够收益，保留较简单的研究方法 |

无信息对照需要说明构造假设，避免随意打乱时间后把本来存在的依赖全部消除。一个候选在一种任务上失败，只能否定或削弱相应主张，不推出所有因子或整个研究方向无效。

## 再次评估

以下是对设计的分析判断，不是实验评分。文献支持方法选择和风险判断，不能代替本项目效果证据。

| 方面 | 当前判断 | 仍需验证的内容 |
| --- | --- | --- |
| 与用户目标一致性 | 较好，保留内部权重学习和结构修改，输出限于研究 | 建议先做波动任务，具体目标定义与资料条件仍需在实验前冻结 |
| 数学定义 | 可形成明确目标与可比较增量；基准证明范围清楚 | 各任务损失与实现是否一致，实际优化是否达标 |
| 训练稳定性 | 有可执行的检查框架，不能凭设计保证无异常 | 输入、梯度、分项支持与不同运行行为 |
| 因子评价 | 比旧版更能区分表示、容量、组合和完整体系 | 对照仍不能穷尽所有解释，结论必须限定方法范围 |
| 自主结构研究 | 有限动作和预算下可以研究，不要求无限扩张 | 是否胜过简单搜索，是否产生新的有效候选 |
| 长期迭代 | 能容纳失败、停滞、简化和重新研究 | 漂移与有限新资料可能使确认缓慢，不承诺单调进步 |
| 本地工程可行性 | 小模型和分阶段比较具有合理路径，属条件性判断 | 实际资料规模、单次训练成本与总搜索成本 |
| 市场有效性 | 尚不能确认本版具有增量 | 需要真实资料上的冻结比较和后续证据 |

资源判断沿用工作区记录的 32 GB 内存与 8 GB 显存作为设计假设，本轮未核验硬件。小型、顺序运行的候选适合作为起点；不承诺具体模型规模、搜索次数、训练时长或并行能力。模型能装入显存，也不意味着大量重复比较在时间上可承受。

本版仍有三个实质弱点。第一，评价方法会限制可发现的表示，简单检验可能漏掉交互结构，因此保留有理由且有预算的组合检验。第二，独立资料和研究时间有限，严格确认会降低迭代速度，因此允许候选长期处于待确认状态。第三，研究目标本身可能不含足够可预测关系，系统应能留下负结果，而非持续加深模型。

对这版最有力的反驳是：管理和对照更严谨，并不会自动创造信号。接受这一点后，仍有理由推进的部分是建立可信的比较能力，而不是预先押注多专家或 agent 必然胜出。

建议进入范围受控的验证准备。首先围绕固定观察范围内的未来波动，形成完整任务约定、一个简单参照和一个候选表示的对照设计；若流程可信，再开放有限结构试验。成功应体现为对一个明确主张获得足够证据，包括接受、限定、否定或暂缓，不能由新增模块数或单次开发分数决定。
